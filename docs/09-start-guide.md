# 09. С чего начать: аккаунт, группа, Studio, публикация

Порядок действий. Пароли и коды от аккаунта не отправляй никому, в том числе мне: для работы они не нужны.

## Шаг 1. Аккаунт (сегодня)
1. Аккаунт Roblox. Лучше отдельный «рабочий» для разработки, но можно и свой.
2. Подтверди почту и включи **двухфакторную защиту (2FA)**. Без неё нельзя публиковать игру для детей.
3. Подтверди возраст: до 18 лет — оценка возраста по лицу, с 18 — документ. Это делается в настройках аккаунта.

## Шаг 2. Группа (сегодня, 100 Robux)
Игру лучше публиковать **от группы, а не от личного аккаунта**:
- в группу можно добавить помощников (строитель, художник, модератор) с разными правами;
- доход от игры копится на счёте группы, и его можно делить;
- вступление в группу — механика роста: в игре даём награду за вступление, а участникам приходят новости;
- если аккаунт пострадает, игра не пропадёт.

**Как создать:**
1. Creator Hub → Groups / Communities → **Create**, цена 100 Robux.
2. Название, например `Greedy Slimes Studio`.
3. Описание: «Official group of Greedy Slimes — codes, updates, events».
4. Временная иконка: слайм из макета.
5. Роли: Owner (ты), Developer (кто строит), Moderator (кто следит за чатом).

## Шаг 3. Открыть игру в Studio (сегодня)
1. Скачай `place/GreedySlimes.rbxl` из репозитория `nnenq/roblooo` (ветка `claude/laughing-bell-hz0yse`) и открой его в Studio.
2. Нажми **Play**: появишься на площади и сможешь обойти весь остров. Через 150 с начнётся Прилив.
3. **File → Publish to Roblox As…**:
   - Creator: твоя группа;
   - название `Greedy Slimes`;
   - пока **Private**.

## Шаг 4. Подключить меня к Studio, чтобы я строил и видел сам
Эта облачная сессия до твоего компьютера не достаёт. Нужна сессия Claude на самом компьютере, где стоит Studio:
1. Установи приложение **Claude Desktop** (вкладка Code) или Claude Code для терминала.
2. Склонируй репозиторий: `git clone https://github.com/nnenq/roblooo`, затем `git checkout claude/laughing-bell-hz0yse`. Открой эту папку в Claude.
   Можно и так: в терминале в этой папке запусти `claude remote-control`. Тогда сессия появится в приложении Claude Code, и ей можно писать даже с телефона.
3. В Studio: **Assistant Settings → MCP Servers → Quick connect → включить Claude Code**. Затем **Assistant → … → Manage MCP Servers → Enable Studio as MCP server**. Перезапусти Studio.
4. Напиши в новой сессии: «продолжаем Greedy Slimes, этап 1, Studio подключён». Дальше я сам читаю сцену, строю, запускаю плейтест и делаю скриншоты.

## Шаг 5. Настройки в Creator Hub (когда игра опубликована)
- **Maturity & Compliance Questionnaire:** честно ответить на вопросы. Наша игра — мультяшная, без насилия и крови, с чатом.
- **Localization:** включить «Use Translated Content» и нужные языки (см. [07](07-languages-devices.md)).
- **Monetization:** пассы и dev products создаются у игры. Прайс — в [05](05-monetization.md). Делаем это на этапе 3, когда код покупок будет готов.

## Шаг 6. Как в 2026 году игра попадает к детям
Основная аудитория таких игр — дети. Roblox ввёл обязательный путь (Roblox Kids 5–8 лет, Roblox Select 9–15):
1. Аккаунт без нарушений, подтверждённый возраст, 2FA.
2. Анкета пройдена, рейтинг Minimal / Mild / Moderate (9+).
3. Один из двух вариантов: **разовый возвратный взнос** за публикацию или подписка **Roblox Plus/Premium 2 месяца подряд**.
4. **Проверка:** сначала игра открыта только для игроков 16+ с подтверждённым возрастом. Нужно **250 уникальных заходов от «вовлечённых» игроков 16+ за 60 дней**: аккаунт давно существует, человек поиграл в игру и делал любую покупку на Roblox за последние 60 дней. Прогресс виден в Creator Hub → Audience Reach.
5. Ускорить проверку можно за возвратные 50 000 Robux. Нам это не нужно.

**Что это значит для запуска:** первые 250 заходов набираем среди старших. Это друзья, Discord, знакомые геймеры, небольшая реклама. Только потом игра станет видна детям.

## Шаг 7. Сообщество (параллельно с разработкой)
- **Discord-сервер:** каналы #updates, #codes, #bug-reports, #fan-art.
- **TikTok и YouTube Shorts:** 15–30 секунд с моментами «весь сервер гонится за Mythic», «лопнул у базы», «Прилив накрыл толпу». Снимаем в Studio, когда механика заработает.
- **Внутри игры:**
  - награда за вступление в группу;
  - коды из Discord;
  - табло «следующее обновление через…»;
  - обновление каждую субботу.

## Шаг 8. Деньги (когда игра начнёт зарабатывать)
- Robux от продаж приходят на счёт группы (или на твой, если игра личная).
- **DevEx** (вывод в реальные деньги):
  - от 13 лет;
  - подтверждённая личность;
  - минимум **30 000 заработанных Robux**;
  - курс **$0.0038 за Robux** (30 000 Robux ≈ $114);
  - выплаты через Tipalti, нужна налоговая форма.
- Если тебе меньше 18, для выплат нужны родители.
