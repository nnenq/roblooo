# 04. Что установить: инструменты и расширения

## Нужна ли Claude Design?

**Обязательно — нет. Главный инструмент — Roblox Studio MCP.**

- Игра в Roblox — это 3D-сцена внутри Studio. Через **официальный MCP-сервер Studio** я могу сам:
  - делать скриншоты вьюпорта (`screen_capture`);
  - читать и править скрипты;
  - выполнять Luau-код в сцене (строить карту);
  - запускать и останавливать плейтест;
  - читать ошибки из Output;
  - нажимать клавиши и мышь за игрока;
  - генерировать меши и материалы (`generate_mesh`, `generate_material`).

  То есть я буду видеть то, что делаю.
- **Claude Design пригодится как дополнение** для 2D-вещей:
  - макеты UI (HUD, магазин, индекс) до того, как верстать их в Studio;
  - композиция иконки и тамбнейлов (расположение текста, цвета);
  - стайлгайд (палитра редкостей, шрифты).

  3D-модели и сами ассеты Roblox она не делает.
- **Вывод:** сначала ставим Studio MCP (ниже). Claude Design подключим на этапе 3 (UI) или 5 (иконки), если захочется увидеть макеты заранее.

## Обязательно (чтобы я мог видеть и строить игру)

### 1. Roblox Studio (последняя версия)
Работает только на Windows и macOS. Поэтому из облака я Studio запустить не могу.

### 2. Claude Code на твоём компьютере
Подойдёт десктоп-приложение Claude (вкладка Code) или CLI. Облачная сессия не дотянется до Studio на твоём ПК, MCP работает только локально.
Ещё вариант: `claude remote-control` в терминале в папке проекта. Такая сессия работает на твоём ПК, но видна в приложении Claude Code, в том числе с телефона.

### 3. Подключить Studio MCP к Claude Code
1. Studio → **Assistant Settings** → **MCP Servers** → раскрыть **Quick connect** → включить **Claude Code**.
   Если Claude Code в списке нет, установи его и перезапусти Studio.
2. Studio → **Assistant** → **…** → **Manage MCP Servers** → включить **Enable Studio as MCP server**.
3. Перезапусти Studio и Claude Code. Должен загореться зелёный индикатор с числом подключённых клиентов.
4. В Claude Code проверь командой `claude mcp list`.

⚠️ Roblox предупреждает, что MCP-клиент может читать и менять открытый плейс. Подключай только то, чему доверяешь, и держи бэкапы (код всё равно лежит в Git).

*Запасной вариант* — комьюнити-сервер `robloxstudio-mcp`: плагин для Studio, в **Experience Settings → Security** включить **Allow HTTP Requests**, потом
`claude mcp add robloxstudio -- npx -y robloxstudio-mcp@latest`. Нужен Node.js.

### 4. Git + этот репозиторий

## Для кода (сильно рекомендую)

### 5. VS Code + расширения
| Расширение | ID | Зачем |
|-----------|-----|-------|
| Luau Language Server | `JohnnyMorganz.luau-lsp` | Автодополнение и проверка типов Luau |
| Rojo | `evaera.vscode-rojo` | Синхронизация файлов с Studio в один клик |
| Selene | `Kampfkarren.selene-vscode` | Линтер: ловит ошибки до запуска |
| StyLua | `JohnnyMorganz.stylua` | Автоформатирование кода |

### 6. Rokit — менеджер инструментов
Ставит из файла `rokit.toml` в репозитории (я создам его на этапе 1) нужные версии:
- `rojo` — синхронизация с Studio;
- `wally` — пакеты;
- `selene`, `stylua`;
- `lune` — запуск Luau-тестов без Roblox.

Установка: https://github.com/rojo-rbx/rokit, затем в папке проекта `rokit install`.

### 7. Плагин Rojo для Studio
После установки Rojo: `rojo plugin install`. Потом в Studio нажми **Connect** во вкладке Rojo, пока запущен `rojo serve`.
